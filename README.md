# KING BOOSTER · aggiornamenti ufficiali

Canale di distribuzione Windows x64 di KING BOOSTER.

Nell'app apri **Aggiornamenti → Controlla aggiornamenti**, quindi **Scarica e
installa**. Impostazioni, libreria e backup personali restano sul PC.

I pacchetti sono verificati tramite una chiave pubblica incorporata nell'app.
L'app usa una firma del progetto per gli aggiornamenti; non è una firma
Authenticode commerciale dell'eseguibile.

Questo repository contiene i pacchetti pubblici firmati e il flusso di
pubblicazione. Non contiene chiavi private, credenziali GitHub o dati dei PC.
Gli utenti non devono collegare un account GitHub per aggiornare l'app.

Il proprietario compila e firma le nuove versioni prima di pubblicarle.
La modifica del codice in una chat, da sola, non genera una release.

Le prestazioni dipendono da hardware, gioco e impostazioni: nessun incremento
fisso di FPS è garantito. Le opzioni incompatibili vengono escluse dall'app.
